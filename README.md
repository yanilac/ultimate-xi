# Ultimate XI

A mobile-first browser game: draft a Premier League XI one spin at a time from any season since 1992, build chemistry like FIFA Ultimate Team, then simulate a full league season. Can you go 38-0-0?

- Scope: [docs/mvp-scope.md](docs/mvp-scope.md)
- Icons: [docs/icons.md](docs/icons.md)
- Game engine: [docs/engine.md](docs/engine.md)
- Player data: [pipeline/README.md](pipeline/README.md)

## Development

```
npm install
npm test          # engine tests
npm run tune      # check the match model against real seasons
```
